마이크로데이터 및 ARIA 예제

1. 마이크로데이터 (Microdata) 기본

마이크로데이터는 HTML 요소에 구조화된 데이터를 추가하는 방법입니다.

Person (사람) 예제

홍길동

직업: 웹 개발자

이메일: hong@example.com

웹사이트: https://example.com

코드 예시

<div itemscope itemtype="https://schema.org/Person"> <h4 itemprop="name">홍길동</h4> <p>직업: <span itemprop="jobTitle">웹 개발자</span></p> <p>이메일: <a itemprop="email" href="mailto:hong@example.com">hong@example.com</a></p> </div>
속성 설명:
  • itemscope: 마이크로데이터 항목의 시작
  • itemtype: 데이터 타입 (Schema.org URL)
  • itemprop: 속성 이름

2. 마이크로데이터: Organization (조직)

웹 개발 회사

주소: 서울시 강남구 테헤란로 123

전화: 02-1234-5678

코드 예시

<div itemscope itemtype="https://schema.org/Organization"> <h3 itemprop="name">웹 개발 회사</h3> <p>주소: <span itemprop="address">서울시 강남구</span></p> </div>

3. 마이크로데이터: Article (기사)

HTML 기초 강의

작성자: 김개발

2024년 12월 10일

HTML의 기본 구조와 시맨틱 태그에 대해 알아봅니다.

코드 예시

<article itemscope itemtype="https://schema.org/Article"> <h2 itemprop="headline">기사 제목</h2> <p itemprop="author" itemscope itemtype="https://schema.org/Person"> 작성자: <span itemprop="name">작성자명</span> </p> <time itemprop="datePublished" datetime="2024-12-10">2024년 12월 10일</time> </article>
장점: 마이크로데이터를 사용하면 검색 엔진이 콘텐츠를 더 잘 이해하고, 검색 결과에 리치 스니펫(추가 정보)을 표시할 수 있습니다.

4. ARIA 기본: role 속성

ARIA는 접근성을 향상시키기 위한 속성들입니다. role은 요소의 역할을 명시합니다.

버튼 역할

클릭 가능한 div

참고: 실제로는 <button> 태그를 사용하는 것이 좋습니다.

코드 예시

<div role="button" tabindex="0">클릭 가능한 버튼</div>
주의: 시맨틱 HTML 태그가 있으면 그것을 먼저 사용하세요. ARIA는 보완용입니다. 예를 들어, <button> 태그가 있으면 role="button"을 추가할 필요가 없습니다.

5. ARIA: aria-label

요소에 접근 가능한 이름을 제공합니다.

아이콘 버튼

코드 예시

<button aria-label="닫기">×</button> <img src="icon.png" aria-label="홈으로 이동">
사용 시나리오: 아이콘만 있는 버튼이나 이미지 링크처럼 텍스트가 없어도 스크린 리더가 목적을 이해할 수 있도록 합니다.

6. ARIA: aria-labelledby

다른 요소의 ID를 참조하여 레이블을 지정합니다.

섹션 제목

이 섹션은 위의 제목과 연결되어 있습니다.

코드 예시

<h2 id="section-title">섹션 제목</h2> <section aria-labelledby="section-title"> <!-- 섹션 내용 --> </section>

7. ARIA: aria-describedby

요소에 대한 추가 설명을 제공합니다.

비밀번호는 8자 이상, 영문, 숫자, 특수문자를 포함해야 합니다.

코드 예시

<input type="password" aria-describedby="password-help"> <p id="password-help">비밀번호는 8자 이상이어야 합니다.</p>

8. ARIA: aria-required와 aria-invalid

폼 필드의 필수 여부와 유효성을 표시합니다.

올바른 이메일 형식이 아닙니다.

코드 예시

<input type="email" aria-required="true" aria-invalid="true" aria-describedby="email-error"> <span id="email-error">올바른 이메일 형식이 아닙니다.</span>

9. ARIA: aria-hidden

장식용 요소를 스크린 리더에서 숨깁니다.

※ 필수 항목 이름

→ 다음으로 이동

코드 예시

<span aria-hidden="true">※</span> <span class="sr-only">필수 항목</span>
sr-only 클래스: 시각적으로는 보이지 않지만 스크린 리더는 읽을 수 있는 텍스트를 만들 때 사용합니다.

10. ARIA: aria-live (라이브 영역)

동적으로 변경되는 콘텐츠를 스크린 리더에 알립니다.

초기 상태

코드 예시

<div aria-live="polite" aria-atomic="true"> <!-- 동적으로 변경되는 내용 --> </div>

aria-live 값

  • off: 알림하지 않음 (기본값)
  • polite: 현재 작업이 끝난 후 알림
  • assertive: 즉시 알림 (중요한 메시지)

11. ARIA 사용 가이드라인

  • ✅ 시맨틱 HTML을 먼저 사용: ARIA는 보완용
  • ✅ 불필요한 ARIA 사용 지양: 시맨틱 태그로 충분하면 ARIA 불필요
  • ✅ 역할 중복 피하기: <button>에 role="button" 불필요
  • ✅ 테스트: 실제 스크린 리더로 테스트
  • ❌ 접근성 향상이 아닌 용도로 사용하지 않기
기억하세요: ARIA는 접근성을 향상시키는 도구입니다. 올바르게 사용하면 스크린 리더 사용자와 키보드 사용자의 경험을 크게 개선할 수 있습니다.

12. 마이크로데이터와 ARIA 비교

항목 마이크로데이터 ARIA
목적 검색 엔진을 위한 구조화된 데이터 접근성을 위한 보조 기술 지원
대상 검색 엔진, 크롤러 스크린 리더, 보조 기술
주요 속성 itemscope, itemtype, itemprop role, aria-label, aria-describedby 등
