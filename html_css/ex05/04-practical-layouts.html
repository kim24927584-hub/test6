2. 카드 행 레이아웃

반응형 카드 그리드를 만듭니다. 화면 크기에 따라 자동으로 줄바꿈됩니다.

카드 1

이것은 Flexbox를 사용한 카드입니다. flex: 1 1 300px로 설정하여 최소 300px 크기를 유지하면서 균등하게 분배됩니다.

카드 2

화면이 작아지면 자동으로 줄바꿈됩니다. flex-wrap: wrap과 함께 사용하면 완벽한 반응형 레이아웃을 만들 수 있습니다.

카드 3

gap 속성을 사용하여 카드 사이의 간격을 쉽게 조절할 수 있습니다. margin보다 훨씬 간편합니다.

/* 카드 행 레이아웃 */ .card-row { display: flex; gap: 20px; /* 카드 간격 */ flex-wrap: wrap; /* 줄바꿈 허용 */ } .card { flex: 1 1 300px; /* 최소 300px, 균등 분배 */ min-width: 0; /* flex-basis보다 작아질 수 있음 */ }
설명:
  • flex: 1 1 300px: grow=1, shrink=1, basis=300px
  • 최소 300px 크기를 유지하면서 남은 공간을 균등 분배
  • 화면이 작아지면 자동으로 줄바꿈

4. 중앙 정렬

요소를 화면 정중앙에 배치합니다.

중앙 정렬된 콘텐츠

이 콘텐츠는 Flexbox를 사용하여 완벽하게 중앙에 배치되었습니다.

/* 완벽한 중앙 정렬 */ .center-container { display: flex; justify-content: center; /* 주축 중앙 */ align-items: center; /* 교차축 중앙 */ min-height: 300px; /* 최소 높이 */ } /* 전체 화면 중앙 정렬 */ .fullscreen-center { display: flex; justify-content: center; align-items: center; min-height: 100vh; /* 전체 화면 높이 */ }
