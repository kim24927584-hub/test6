사용된 CSS 기법

1. 외부 폰트 적용

Google Fonts에서 Noto Sans KR 폰트를 가져와 사용했습니다.

@import 또는 <link> 태그로 폰트 연결

2. 그라데이션 배경

linear-gradient를 사용하여 아름다운 그라데이션 배경을 만들었습니다.

background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);

3. border-radius로 둥근 모서리

border-radius를 사용하여 카드와 아바타를 둥글게 만들었습니다.

border-radius: 20px; /* 카드 */
border-radius: 50%; /* 원형 아바타 */

4. box-shadow로 그림자 효과

box-shadow를 사용하여 입체감을 주었습니다.

box-shadow: 0 10px 30px rgba(0,0,0,0.3);

5. 텍스트 스타일링

font-weight, font-size, line-height 등을 사용하여 텍스트를 스타일링했습니다.

font-weight: 700; font-size: 1.8rem; line-height: 1.6;

6. 색상 사용

16진수 색상 코드를 사용하여 정확한 색상을 지정했습니다.

color: #2c3e50; background-color: #e3f2fd;

7. 호버 효과

:hover 가상 클래스를 사용하여 인터랙티브한 효과를 추가했습니다.

.btn:hover { transform: translateY(-2px); }
